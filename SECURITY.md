# Security policy

## Reporting a vulnerability

Please report vulnerabilities privately, not in public issues:

- GitHub: [report a vulnerability](https://github.com/illesnagy1/ctfp/security/advisories/new)
- Email: illesnagy@edu.bme.hu

Include what you found, how to reproduce it, and the version or commit. You'll get a reply within a week; please give us a reasonable time to fix the issue before disclosing it.

## Scope

The CTF+ platform itself: the api (`api/`), the frontend (`frontend/`) and the deployment files (`compose.yml`, `Containerfile`s).
